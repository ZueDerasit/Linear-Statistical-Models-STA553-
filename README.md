# STA553: Linear Statistical Models

This repository contains learning materials, R code, lab activities,
R Markdown templates, assignments, and mini-project resources for STA553.

## Course Overview

STA553 introduces statistical modelling using R, with emphasis on
linear statistical models and their applications.

## Course Topics

1. Correlation
2. Simple Linear Regression
3. Model Adequacy
4. Multiple Linear Regression
5. Generalized Linear Models

## R and R Markdown

Students will use R for statistical analysis and R Markdown
to produce reproducible statistical reports in HTML or PDF format.

## Repository Structure

- `00-R-for-STA553` — R skills required for the course
- `01-Correlation` — Correlation
- `02-Simple-Linear-Regression` — Simple Linear Regression
- `03-Model-Adequacy` — Model assessment and diagnostics
- `04-Multiple-Linear-Regression` — Multiple Linear Regression
- `05-Generalized-Linear-Models` — Generalized Linear Models
- `06-Statistical-Reports` — R Markdown reports and templates
- `07-Assignments` — Assignment materials
- `08-Mini-Project` — Mini-project materials
- `Datasets` — Datasets used in examples and labs
- `Resources` — References and useful resources
